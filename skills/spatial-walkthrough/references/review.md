# 视觉与交付检查表

## 构图与气氛

- 首屏在一个镜头内交代入口、楼层关系和空间主体。
- 让铺装、木构、植栽与光照形成可辨识的材质层次。检查夜景是否仍看得清台阶和主通路。
- 每幕只突出一个空间重点。实际播放一遍，检查转场是否掠过墙体、栏杆、顶棚或树冠。
- 在窄屏检查标题、热点和导览按钮的遮挡，兼顾图文对比度与操作区域。

## 交互与运行

- 从静态站点路径加载所有资源。检查首屏、拖动缩放、点位跳转、镜头预设和氛围开关。
- 测试导览的首尾、暂停、重播、退出和减少动态效果。检查移动端和无 WebGL 时的界面。
- 用经过审核的素材部署，验证线上入口和资源能从实际站点路径打开。

## 发布审查

- 查看文件清单和 Git 暂存区。对图像、视频抽帧、模型属性与注释做人工核查。
- 删除原始 CAD、项目源图纸和精确源数据，以及申报文件、内部屏录和私有链接。核对依赖版权。
- 运行发布扫描。新增二进制文件应先审查画面、模型结构、元数据和许可，再进入发布清单。
