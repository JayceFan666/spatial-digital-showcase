# 视觉与交付检查表

## 构图与气氛

- 首屏在一个镜头内交代入口、楼层关系和空间主体。
- 让铺装、木构、植栽与光照形成可辨识的材质层次。检查夜景是否仍看得清台阶和主通路。
- 每幕只突出一个空间重点。实际播放一遍，检查转场是否掠过墙体、栏杆、顶棚或树冠。
- 在窄屏检查标题、热点和导览按钮的遮挡，兼顾图文对比度与操作区域。

## 交互与运行

- 从静态站点路径加载所有资源。检查首屏、拖动缩放、点位跳转、镜头预设和氛围开关。
- 测试导览的首尾、暂停、重播、退出和减少动态效果。检查移动端和无 WebGL 时的界面。
- 用经过审核的素材部署，验证线上入口和资源能从实际站点路径打开。

## 发布前检查（维护者）

1. **确认发布范围。** 原始 CAD、带尺寸的图纸、精确坐标和标高、申报文件、内部屏录及私有链接留在本地。来源或公开权限不明的素材不发布。
2. **人工核对内容。** 检查代码注释与路径、网页链接、资源包、模型属性、图片画面和媒体元数据；视频应抽帧查看。确认依赖版权和素材可公开的范围。
3. **扫描待发布文件。** 先从仓库根目录扫描工作树，只暂存审核通过的文件，再扫描 Git 暂存区，确认将要提交的内容。

```sh
python3 scripts/prepublish.py --tree
# 只用 git add 暂存已审核的发布文件，再扫描 Git 暂存区
python3 scripts/prepublish.py
```

脚本可提示常见的私有文件、路径、内嵌资源和密钥，不能替代对图片、视频、模型数据或授权的人工确认。上线后，从实际站点复查链接与资源是否可用。
