# 空间数字展示与漫游

本 Skill 出自 [Spatial Digital Showcase · @JayceFan666](https://github.com/JayceFan666/spatial-digital-showcase)。如基于本 Skill 改编或转载，建议保留这条来源说明，便于使用者找到原版。

先复用已经给出的目标、文件和偏好。新任务或范围明显变化时，检查业务目标、观众、关键功能、视觉参考和交付方式。只问会改变成品方向的缺口。能用结构化选项时，用中文提出一至三个简短问题，给出有依据的推荐。工具不可用时用对话询问。已确定的事项不重问，可逆细节自行处理。关键答复到达前，推进可独立完成的资料整理与审查。

1. 用 [任务书](templates/brief.md) 确认必讲的空间关系、可用素材和公开边界，记录尚待核实的部分。
2. 按项目搭建结构轮廓、动线、楼层和开口。用分组管理可切换的绿化、顶棚和人流。几何与镜头需要针对新空间重新制作。
3. 用 [镜头与点位模板](templates/scenes.json) 定义镜头位置、目标、停留时间、点位文案及光照。优先让空间关系在画面中可见，再写说明。
4. 将导览和自由探索接到同一个模型。导览提供暂停、上一幕、下一幕和退出。兼顾触屏、键盘与减少动态效果设置。
5. 按 [视觉与交付检查表](references/review.md) 验收。计划对外发布时，确认发布范围与授权，检查资产和待提交文件。CAD 或其他原始项目图纸可在本地参考，任何发布文件都不得包含这些材料或可追溯到它们的精确数据。发现无法核实的内容时，把具体疑点列出来并留在私有工作区。
